# 🌸 마커 길퀘 관리봇

테일즈런너 길드 **[ 마커 ]** 의 길드 퀘스트(길퀘)·점령·명예/우수 관리를 디스코드에서 처리하는 봇이에요.
점수와 길드원 정보는 **구글 스프레드시트**에 저장되고, 대부분의 기능은 **카드와 버튼**으로 동작해요.

> Python · discord.py 2.7 · gspread · Pillow

---

## 📌 한눈에 보기

| 영역 | 하는 일 |
|---|---|
| 🗡️ 길퀘 | 점수 체크, 이번 주 요일별 점수, 길퀘 불가 사유, 리마인드 |
| ⚔️ 점령 | 매주 월요일 투표 게시 → 참여/불참/기타 → 관리자 확인 시 점수 기록 |
| 🏆 명예/우수 | 미리보기 → 확정 시 등급·역할 변경 + 명예의 전당 이미지 게시 |
| 👥 길드원 | 입장 카드(승인 버튼), 퇴장 카드, 길드원 목록 카드 |
| 🔔 알림 | 경고 3회 누적, 입장 대기 방치, 점령 투표 미참여 |
| 🔊 편의 | 음성방 자동 생성, 한글 서버 로그, 낚시 경험치 계산기 |

## ⌨️ 슬래시 명령어

| 명령어 | 권한 | 설명 |
|---|---|---|
| `/체크 <점수> <길드원들> [날짜]` | 길마·서마 | 길퀘 점수 체크 (같은 날 재입력 시 마지막 값으로 덮어씀) |
| `/이번주길퀘확인` | 전체 | 내 이번 주 요일별 길퀘 점수 (채널 공개 카드) |
| `/길퀘불가사유 <사유>` | 전체 | 이번 주 길퀘 불가 사유 등록 (토요일까지) |
| `/길퀘체크제외 <닉네임> <기간> <사유> [날짜]` | 길마·서마 | 길드원 N주 체크 제외 대리 등록 |
| `/리마인드` | 길마·서마 | 이번 주 길퀘 미완료자 채널 멘션 + 개인 DM |
| `/대시보드설치` | 길마·서마 | 현재 채널에 대시보드 카드 설치 |
| `/점령투표` | 길마·서마 | 이번 주 점령 투표 수동 게시 (이미 있으면 안 올림) |
| `/명예의전당 [연월]` | 길마·서마 | 현재 명예/우수 등급으로 명예의 전당 이미지 게시 |
| `/공지사항설치` | 길마·서마 | 현재 채널에 공지사항 카드 설치 (길드 규칙 · 임시 음성 채널 · 명예/우수 혜택 · 용병 안내) |

> 서버 소유자는 역할 매핑과 관계없이 모든 길마·서마 권한을 가져요.

## 🃏 카드 · 버튼

### 👥 길드원 목록 (길드원관리 채널 · 봇 시작 시 자동 설치)
- 등급 이모지 + 닉네임 + 경고 횟수 (등급순 → 가나다순)
- **[탈퇴]** 닉네임 팝업 → 확인 카드 → 시트 데이터 삭제
- **[명예우수집계]** 연월 입력 → **미리보기 카드**(명단·점수·등급 변경 예정) → **[확정]** 시
  등급 변경 · 디스코드 역할 변경 · 포인트 반영 마감 · 명예의 전당 게시
- **[명예우수설정]** 명예·우수 정원 입력 → 일반 정원 자동 계산
- **[🔄]** 목록 갱신 (누구나)

### 🚪 입장 / 퇴장
- 입장 시 **입장대기** 역할 자동 부여 + 입장 카드
  - **[길드원 승인]** 닉네임 팝업 → 시트 등록 · 입장대기→일반 · 서버 닉네임 변경
  - **[게스트 승인]** 입장대기→게스트
- 퇴장 시 퇴장 채널에 카드 (함께한 기간)

### ⚔️ 점령 투표
- **[✅ 참여] [❌ 불참] [💬 기타(사유)]** — 관리자 확인 전까지 언제든 변경
- **[🔒 관리자 확인]** 체크박스 팝업으로 실제 참여자 선택 → 8점 기록 후 마감

### 📊 대시보드 · 🛠 관리 패널
- 대시보드: 길퀘 남은 횟수 / 주간 순위 / 명예·우수 예상 / 누적 경고 (◀ ▶ 🔄)
- 관리 패널(길퀘관리 채널): 대시보드 · 내 현황 · 시트 · 도움말 + 관리자용 가입 · 탈퇴 · 체크 · 점령 · 관리
  (등급 변경 · 역할 관리 · 시트 요약 · 길퀘불가 · 인원수 증감 · 명예우수계산 · 리마인드 · 경고처리)

### 🔊 음성방 자동 생성
- 지정 채널에 글을 쓰면 그 이름으로 음성채널 생성 + 카드(**[종료]**)
- 모두 나가면 3분 뒤 자동 종료, 같은 이름의 진행 중인 방이 있으면 안내

### 🎣 낚시 경험치 계산기
- 설치된 카드에서 색깔·윙·퍼센트·획득 경험치를 넣으면 도착 계급과 퍼센트 계산

## ⏰ 자동 작업 (KST 기준)

| 시점 | 작업 |
|---|---|
| 매시간 | 시트 **요약** 탭 갱신 · 입장 대기 24시간 초과 확인 |
| 월요일 00:00 | 지난주 **경고 정산** → 3회 도달자 관리 채널 알림 · 3개월 지난 반영 포인트 정리 · **점령 투표** 게시 |
| 금요일 00:00 | 길퀘 미완료자 개인 DM + 리마인드 채널 멘션 |
| 금요일 12:00~ | **점령 투표 미참여자** 개인 DM (투표 카드에 발송 표시) |
| 일요일 00:00 | 길퀘 미완료자 리마인드 |

> 자정 작업이 실패하면 그날 안에 매시간 다시 시도해요.

### 🔔 관리 알림 (관리 채널)
| 알림 | 조건 | 보내는 곳 |
|---|---|---|
| ⚠️ 경고 3회 누적 | 주간 정산에서 경고가 3회에 처음 도달 | 관리 채널 카드 |
| ⏰ 입장 승인 대기 | 입장 카드가 24시간 넘게 미승인 | 관리 채널 카드 + 길마·서마 전원 DM |

## 📋 경고 · 명예/우수 규칙

**주간 경고 정산** (월요일, 지난주 월~일 기준)
1. 차감: 길퀘 7회 매일 완주 −1, 점령 참여 −1 (0 미만 불가)
2. 부여: 길퀘 2회 미만이고 길퀘 불가 사유가 없으면 +1

**명예/우수 집계**
- 반영되지 않은(`reflection_yn = N`) 포인트를 날짜와 관계없이 멤버별로 합산 (길퀘 + 점령)
- 길마·서마 등급만 제외, 점수 높은 순으로 명예 정원 → 우수 정원 (동점은 닉네임 가나다순)
- 확정하면 뽑힌 사람은 명예/우수, 기존 명예·우수인데 탈락하면 일반 (시트 + 디스코드 역할)

## 🔧 채널 · 역할 설정

채널 ID는 각 모듈 상단 상수로 지정돼 있어요.

| 상수 | 파일 | 용도 |
|---|---|---|
| `WELCOME_CHANNEL_ID` / `LEAVE_CHANNEL_ID` | welcome/welcome.py | 입장 / 퇴장 카드 |
| `MEMBER_CHANNEL_ID` | memberlist/memberlist.py | 길드원 목록 |
| `VOTE_CHANNEL_ID` | vote/vote.py | 점령 투표 |
| `HALL_CHANNEL_ID` | halloffame/halloffame.py | 명예의 전당 |
| `ALERT_CHANNEL_ID` | alerts/alerts.py | 관리 알림 |
| `LOG_CHANNEL_ID` / `DELETE_WATCH_CHANNEL_ID` | serverlog/serverlog.py | 서버 로그 / 삭제 감시 채널 |
| `WATCH_CHANNEL_ID` / `CATEGORY_ID` | voice/voice.py | 음성방 생성 채널 / 카테고리 |
| `CHECK_LOG_CHANNEL_ID` | quest/quest.py | /체크 기록 |
| `REMIND_CHANNEL_ID` | batch/batch.py | 금요일 리마인드 |

역할(길마·서마·명예·우수·일반·입장대기·게스트)은 `guild_config.json`에 서버별로 저장되고,
관리 패널 → **역할 관리**에서 바꿀 수 있어요.

## 🚀 실행

### 환경 변수 (`.env`)
```env
DISCORD_TOKEN=봇 토큰
GUILD_ID=서버 ID          # 있으면 명령어가 즉시 반영돼요
GOOGLE_CREDENTIALS={...}  # 서비스 계정 JSON (한 줄)
SPREADSHEET_ID=시트 ID
```

### 라이브러리
```bash
pip install -r requirements.txt   # discord.py>=2.7, gspread, oauth2client, python-dotenv, pillow
python bot.py
```

### 디스코드 개발자 포털
- **Message Content Intent**, **Server Members Intent** 켜기
- 봇 역할을 입장대기·일반·게스트·명예·우수 역할보다 **위**에 두기 (역할 부여·닉네임 변경)

### ⚠️ 배포할 때
`guild_config.json`은 봇이 실행 중에 기록하는 파일이에요 (역할 매핑, 설치된 카드 위치, 배치 실행 기록).
**호스팅에 있는 파일을 덮어쓰지 마세요.** 덮어쓰면 카드가 중복되거나 배치가 다시 실행될 수 있어요.
