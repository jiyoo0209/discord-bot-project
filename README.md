# 디스코드 길드 퀘스트 관리 봇 기능 명세

## 1. `/증가`, `/감소` ★개발완료 테스트 예정

### 권한
- 길드마스터

### 명령어
```text
/증가 <등급> <숫자>
/우수 <등급> <숫자>
```

### 기능
- `user_rank` 테이블의 `rank_cnt` 업데이트
- 기존 인원수와 변경된 인원수의 차이를 계산
- 차이만큼 일반 길드원 수(`일반`)를 자동 반영

### 예시
```
기존
명예 : 3
일반 : 27

/증가 명예 2

변경
명예 : 5
일반 : 25
```

# 2. `/체크`

### 권한
- 길드마스터
- 서브마스터

### 명령어
```text
/체크 <점수> <길드원 목록>

예)
/체크 5 카카오톡 주땅 충묘 냥달
```

### 기능
각 길드원마다 `user_point` 테이블에 INSERT

| 컬럼 | 값 |
|------|----|
| point | 입력 점수 |
| point_date | 오늘 날짜 |
| capture_yn | N |
| reflection_yn | N |

# 4. 배치 - 점령 미참여 경고 처리

### 실행 시간

### 기능
- 이번 주 점령 참여 여부 확인
- 점령을 하지 않은 길드원
- `warning > 0` 인 경우만

```

```

# 5. `/가입`

### 권한
- 길드마스터
- 서브마스터

### 명령어
```text
/가입 <길드원이름>

예)
/가입 카카오톡
```

### 기능

#### 1. user 테이블 INSERT

#### 2. user_rank 업데이트

```
rank_name = 일반

rank_cnt +1
```

#### 3. 디스코드 역할 변경

```
입장대기 제거
↓

일반 역할 부여
```

### 예외

이미 등록된 이름이면

```
이미 등록된 유저입니다!
```

# 6. `/탈퇴`

### 권한
- 길드마스터

### 명령어
```text
/탈퇴 <길드원이름>

예)
/탈퇴 카카오톡
```

### 기능

#### 1. 해당 유저 등급 조회

```
rank_name 확인
```

#### 2. 해당 rank의 인원수 -1

#### 3. 아래 데이터 삭제

- user
- user_point
- quest_deny_reason

### 예외

존재하지 않는 경우

```
{user_name}은(는) 존재하지 않는 유저입니다!
```

# 7. `/명예우수계산`

### 권한
- 길드마스터
- 서브마스터

### 기능

`user_point`

```
reflection_yn = N
```

인 데이터만 조회

↓

현재 명예/우수 인원수(`rank_cnt`)를 기준으로 계산

↓

계산 완료 후

```
reflection_yn = Y
```

일괄 업데이트

# 8. `/길퀘불가사유`

### 권한
- 전체 길드원

### 명령어
```text
/길퀘불가사유 <사유>

예)
/길퀘불가사유 개인사정
```

### 기능

`quest_deny_reason`

INSERT

### 제한 사항

#### 이번 주(월~토)에 이미 등록한 사유가 있는 경우

```
이번주에는 이미 등록된 사유가 있습니다!
```

#### 일요일 등록 시

```
토요일까지만 등록 가능합니다!
```
